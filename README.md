# AIMS-mini

Ứng dụng mẫu được xây dựng phục vụ các bài thực hành môn **Quản lý cấu hình phần mềm – IT3180**.

## 1. Giới thiệu

AIMS-mini là ứng dụng quản lý cửa hàng DVD, mô phỏng một số chức năng cơ bản của hệ thống quản lý bán hàng.

## 2. Chức năng chính

- Quản lý giỏ hàng (Cart).
- Thêm và quản lý DVD.
- Tìm kiếm DVD theo tiêu đề và danh mục.
- Sắp xếp DVD theo tiêu đề và giá.
- Kiểm tra các chức năng thông qua Unit Test.

## 3. Công nghệ sử dụng

- **Ngôn ngữ:** Python
- **Quản lý phiên bản:** Git
- **Nền tảng lưu trữ mã nguồn:** GitHub
- **Kiểm thử:** Python `unittest`

## 4. Hướng dẫn chạy chương trình

Yêu cầu: Python 3 đã được cài đặt.

Chạy chương trình:

```bash
python main.py
```

## 5. Chạy kiểm thử

```bash
python -m unittest discover -s tests -v
```
